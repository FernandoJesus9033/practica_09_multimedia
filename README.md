## 🎯 Objetivo
Integrar captura de imágenes y lectura de sensores para crear interacción con hardware del dispositivo.

## 🛠️ Requisitos
- Flutter SDK 3.47.2+
- Visual Studio Code
- Paquetes: image_picker, sensors_plus
- Permisos de cámara en Android

## 📦 Instalación
git clone https://github.com/FernandoJesus9033/practica_09_multimedia.git
cd practica_09_multimedia
flutter pub get

## 🚀 Ejecución
flutter run

## ✨ Funcionalidades
- **Ejemplo Guiado:** Captura de foto y lectura del acelerómetro.
- **Ejercicio Evaluable:** Bitácora de inspección con foto, fecha/hora, acelerómetro, giroscopio y tarjeta de evidencia.
